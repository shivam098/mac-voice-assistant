The files were already present for this run. An earlier run after downloading them reported 9.443 s to first load,
461 ms median and 1.917 s slowest, with the same score. Its default-verbosity summary incorrectly said CPU-only:

[the Windows app](https://github.com/shivam098/windows-voice-assistant/blob/main/src/VoiceAssistant.App/Brain/BrainFiles.cs).
The benchmark exercised the local planner, including the no-action joke fixture; it did not exercise the microphone.
